📚 University Data Hub

Welcome to the University Data Hub!

This project is created to help students by providing valuable university-related data, resources, and guidance in one place.
Whether you’re a new student, a senior, or just someone looking for quick information, this repository is for you.

🌟 Purpose
I created this project with the aim to:

Support fellow students by sharing important, informative and up-to-date data.

Save time by organizing commonly needed information.

Build a helpful community where knowledge is shared freely.

Share this repo to help others!
